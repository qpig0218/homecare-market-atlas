# 居護市場研究室｜The One AITech

臺灣居家護理資訊系統與行政減量機會的互動市場研究網站。

## 網站功能

- 20 條產品及替代方案線索；搜尋、分類與最多三項並排比較。
- 市場資料圖表、手機方案與機構方案財務試算。
- 行政工作機會、使用者證據、12 項待執行測試方案。
- 完整主報告與九份證據頁，保留來源與研究限制。

## GitHub Pages

使用分支發布：main 分支的 /docs 目錄。docs 內為可直接發布的靜態檔案，不需要伺服器或 API 金鑰。

## 更新與驗證

Node.js 20 以上，執行 npm install、npm run build、npm test。編輯 research.json 後重新產生 docs/research-data.js 與資料快照。網站互動程式位於 docs/app.js、docs/model.js，樣式為 docs/styles.css。

## 研究邊界

研究快照日期：2026-10-27。20 項是產品及替代方案線索，不能解讀為已窮盡市場或 20 家獨立的居護系統商。所有競品登入後端到端實測數為 0；公開資料、廠商主張、使用者回饋與推論分開標示。財務結果採可調整假設，不代表市場預測。原始 Pages 連結可能需要個別存取權限；完整研究文字已內嵌於網站閱讀器。

網站本身不收集使用者資料、不連接病人或機構系統，所有互動與試算均在瀏覽器本機執行。
